# VixForge Editor

The shader inspector behind the VixForge shaders. It draws the sections you edit in, the copy, paste
and reset on each header, the material lock, and the tools under **VixenTools > VixForge Editor**.

There is nothing to set up. It loads itself whenever you select a material on a VixForge shader.

The guides are in the Hub: **VixenTools > Shader Hub**.
