Vixen Hub

Your central command nexus. The Vixen Hub is a fully dynamic, 8-tab developer dashboard powered by a native Markdown-to-UIToolkit parser, autonomous update detection, and a cyberpunk UI layer that integrates directly into the Unity Editor.

  • Autonomous Update HUD: A SceneView-injected cyber badge appears automatically whenever the package version changes. The notifier reads package.json, compares stored versions, and spawns a neon update badge that routes directly to the Changelog tab.
  • Dynamic DOM Bridges: Every tab - Dashboard, Core Modules, Network, Support, Changelog - is built using live UIElements containers. Switching modes dynamically rebuilds the DOM without freezing the Editor or triggering layout thrashing.
  • Native Markdown Engine: The Hub parses README.md and CHANGELOG.md directly from the package. Headings, lists, separators, and inline formatting are converted into UIToolkit elements with cyber-styled typography and animated separators.
  • Action Delegates: Every module card in the Hub is backed by a direct C# delegate. Clicking a button executes the corresponding Unity menu command instantly - no reflection hacks, no string-based routing, no fragile editor scripts.
  • Core Module Launchpad: Provides one-click access to the entire Vixens Toolbox suite: Badge Studio, Quest Conversion Engine, Optimization Suite, PhysBone Mapper, Animation Workbench Pro, Pipeline Preset Manager, and more.
  • SDK & Package Version Sync: Automatically extracts the installed VRCSDK version from package.json using regex-based detection across com.vrchat.base, avatars, and worlds packages. Displays live version info in the header banner.
  • Changelog Markdown Parser: Parses all version blocks from CHANGELOG.md and exposes them through a dropdown selector. Each version renders its markdown content into a scrollable cyber-styled panel.
  • Network Routing Panel: Provides direct links to GitHub, Discord, X/Twitter, YouTube, Issue Tracker, and storefronts. All links are rendered as cyber-cards with animated hover states.
  • Support Buttons and Links: A dedicated tab for supporting the developer, complete with Ko-Fi, Gumroad, Patreon, CashApp, and storefront links - all rendered through the same markdown-driven UI pipeline.
  • Zero-Latency UI: The Hub uses flex-driven UIToolkit layouts, async-safe initialization, and cached markdown parsing to ensure instant tab switching even in large Unity projects.

Avatar Optimization Suite

A multi-threaded, topology-aware execution matrix engineered to collapse avatar complexity with surgical precision.

  • Vertice Mesh Welder: Utilizes a UV-locked XYZ+UV+Normal hash to merge vertices with sub-millimeter precision. Automatically extracts and re-maps all blendshape frames, ensuring facial expressions remain pixel-perfect even after aggressive topology collapse.
  • Dual-Shielding: Scans material slots, submesh indices, and Humanoid bone weights to isolate protected regions (eyes, visor, jaw, mouth interior, facial decals). These zones are mathematically excluded from the decimation grid, guaranteeing zero distortion to expressive topology.
  • Multipass Targeted Microweld: Iteratively reduces triangle counts using a threshold-ramping algorithm. Each pass recalculates spatial seams while strictly locking UV coordinates, ensuring no texture tearing even under extreme polygon reduction.
  • Blendshape Memory Engine: Captures every delta frame (verts, normals, tangents) before welding, then re-projects them onto the optimized mesh using a master translation map. Guarantees 1:1 expression fidelity after topology collapse.
  • Bone Collapse & Weight Transfer: Identifies dead-end leaf bones and safely transfers their vertex weights to parent transforms. Reduces rig complexity without compromising animation integrity or physics behavior.
  • Tight-Fit Bounds Rebuilder: Recalculates skinned mesh bounds using 8-corner world-to-root projection, eliminating oversized bounding boxes that cause off-screen rendering and GPU overdraw.
  • Orphaned Transform Purger: Detects and removes empty GameObjects with zero components and no vertex influence, flattening bloated hierarchies and reducing serialization overhead.
  • Disabled Component Stripper: Automatically removes hard-disabled Behaviours (excluding Animator) to reduce build size and eliminate dead logic paths.
  • VRAM Reduction Pipeline: Uses ImageMagick to downscale all unique textures - including those hidden inside VRCFury dependencies - while skipping RenderTextures to avoid corruption. Provides deterministic, offline VRAM control with zero cloud dependency.
  • Physics Node Depth Sorter: Maps all PhysBones, Colliders, Contacts, and Constraints, then sorts them by hierarchy depth. Enables safe culling of leaf-node physics without destabilizing core rig behavior.
  • PC & Quest Pipeline Validator: Performs full SDK-level compliance checks, including illegal component detection, shader whitelist enforcement, joint removal, camera stripping, and performance-rank-based warnings.

Quest Conversion Engine

A fully non-destructive, enterprise-grade conversion pipeline engineered to translate complex PC avatars into VRChat Mobile–compliant builds.

  • Magick.NET Linear Downsampling: Executes gamma-correct, high-fidelity texture reduction using ImageMagick’s offline pipeline. Supports 256–2048px targets, preserves micro-contrast, and automatically skips RenderTextures to avoid corruption. Every texture is processed deterministically for perfect VRAM control.
  • Deep Material Spider: Traverses SerializedObject streams, Animator controllers, VRCFury components, nested prefabs, and hidden dependency chains to extract every material and texture used by the avatar. Guarantees 100% accurate VRAM mapping - even for assets buried inside outfit toggles or animation clips.
  • Auto-Cull Purge: Automatically flags and locks mobile-incompatible components including Cameras, Lights, Cloth, Rigidbodies, Joints, Line/Trail Renderers, Particle Systems, and Raycasts. Each is displayed with neon-red, non-overrideable toggles to prevent accidental inclusion.
  • Interactive Topology: Provides a full UI Toolkit panel for reviewing and overriding Quest limits. PhysBones, Colliders, Contacts, Constraints, Animators, and Particle Systems are sorted by hierarchy depth and capped according to your selected performance rank (Excellent → Poor).
  • Face Tracking & VRCFT Hunter-Killer: Detects VRCFaceTracking templates, adjerry91 prefabs, VRCFury face-tracking branches, and namespace-based FT components. Automatically locks them for removal to maintain Quest compliance.
  • Non-Destructive Prefab Isolation: Clones the avatar into a dedicated Quest workspace under Assets/Vixens Toolbox/QuestConversion, ensuring your PC avatar remains untouched while the mobile clone undergoes full transformation.
  • Hard-Cap Performance Mapping: Calculates total triangles, skinned meshes, material slots, unique materials, unique textures, and all physics nodes. Highlights violations using color-coded severity markers and applies VRChat’s mobile limits mathematically.
  • Texture Map Selection: Displays every detected texture with resolution metadata and toggleable processing flags. Supports “Select All / Deselect All” batch operations for rapid iteration.
  • Animator & Physics Isolation: Maps every Animator, PhysBone, Collider, Contact, Constraint, and Raycast into a structured topology tree. Each node includes a relative path, depth score, and keep/cull toggle.
  • Mobile Shader Targeting: Automatically converts materials to your selected Quest shader: VRCMobileToonStandard, VRCMobileToonLit, VRCMobileStandard, VRCMobileMatcap, or Unity’s Mobile Standard.
  • Performance Rank Enforcement: Applies dynamic caps based on your chosen rank: Excellent, Good, Medium, Poor. These caps govern allowed PhysBones, Contacts, Animators, Particles, and more.

Animator Forge

A two-in-one avatar animator tool: diagnose broken controllers and forge fully-rigged toggles in a single click.

  • Animator Doctor: Scans every playable-layer controller plus the Expression Parameters and Menu, then lists ranked findings with one-click fixes:
    • Missing parameters, including VRChat built-ins like Seated, AFK, and the Gesture values, re-added with the correct type
    • Broken mixes of Write Defaults across states
    • Menu controls and toggles bound to parameters missing from the Expression Parameters
    • Synced-parameter cost overflow, duplicate or mismatched parameters
    • Dead zero-weight layers and invalid transitions
    Each finding has a Locate button and, where safe, a Fix, plus a Fix all safe issues batch.
  • Write Defaults Normalizer: Detection and repair follow the widely-used VRCFury model, grouping states as normal, Direct blend tree, or additive, taking the target from the FX layer's majority, and always forcing Direct blend trees and additive layers on. It reports the exact offending states and only changes anything on request.
  • Empty-Clip Repair: Catches the SDK's "Write Defaults disabled where the animation clip is either missing or empty" warning using VRChat's own scan logic, then fixes it by assigning a shared inert clip that carries a single harmless property.
  • Rig Builder: Builds complete, ready-to-use rigs with no manual wiring, generating the Expression parameter, the menu control or submenu, the FX layer with its states and transitions, and the animation clips:
    • GameObject toggle (one or many objects at once)
    • Blendshape toggle and blendshape slider (radial dial)
    • Material swap
    • Exclusive group (a radio set where enabling one option disables the rest)
    New states are matched to the avatar's own Write Defaults convention.
  • Non-Destructive by Design: Reuses or creates the FX controller and expression assets, clones read-only sample controllers before touching them, and never deletes existing layers or parameters.

VixenWear Latex Ultra Shader

A high-fidelity, dual-lobe PBR surface shader engineered for synthetic materials. It ships a full industry-standard GGX BRDF stack with anisotropy, thin-part transmission, tinted clearcoat, mirror-correct view math, and the deepest Light Volumes + LTCGI integration of any creator-facing shader on the platform - now in two variants (base plus a tessellation-free Latex Ultra SPS clone for VRCFury SPS patching) with a full liquid surface system: a master Polish gate, Poiyomi/Mochie reflection & specular masks, wet/run-off with geometry water droplets, and gravity-aligned melting goo.

  • GGX BRDF Pipeline: Direct and indirect specular use D_GGX (Trowbridge-Reitz), V_SmithJointGGX, F_Schlick, and a Karis split-sum (EnvBRDFApprox_AB) for environment specular - no per-mip BRDF integral required. Direct diffuse uses Burley with proper retroreflection at grazing angles. Optional Filament/Frostbite multi-scatter energy compensation preserves bright metal highlights at high roughness.
  • Anisotropic Specular & Transmission: Burley anisotropic alpha split (D_GGX_Aniso + V_SmithJointGGX_Aniso) with rotation control produces true latex-stretch highlights, not a brushed-metal hack. A separate thin-part transmission term (Burley/Filament back-light with Beer-Lambert absorption) gives ears, fingers, and latex membranes physically correct light bleed.
  • Tinted Clearcoat & Geometric Spec AA: _CC_Tint + _CC_F0 give the coat a coloured cast and custom Fresnel base reflectance. Toksvig-style GeometricSpecAA roughens both base and clearcoat normals from screen-space derivative variance, killing the spec-sparkle aliasing that hammered high-gloss surfaces at mid-distance.
  • VRChat Mirror Camera Fix: vw_CameraPos() and vw_WorldViewDir() read the actual rendering camera from UNITY_MATRIX_I_V (per-eye correct under single-pass instanced) instead of _WorldSpaceCameraPos. Routed through viewDir, GI viewDir, parallax raymarch, and clearcoat reflection so specular and parallax math is finally correct in VRChat mirrors.
  • Liquid Surface System (Polish, Wet & Goo): A master _UsePolish gate collapses the whole clearcoat/SSS/transmission stack to a flat base on demand. A wet/run-off layer soaks the latex with a near-mirror film, dielectric sheen, and animated rivulets, while a PC-only geometry stage emits real water droplets that swell, pinch off, and fall away with sway, body-slide, and floor-splat physics. Gravity-aligned melting goo sags the mesh in the displacement stage with floor-pooling and per-strand sway. Poiyomi/Mochie reflection & specular masks drop in packed maps via a one-click setup button.
  • Poiyomi / Substance Drop-In Compatibility: Per-channel selectors (_PBR_Met_Ch, _PBR_Smooth_Ch, _PBR_AO_Ch, _PBR_Height_Ch) plus invert toggles let Poiyomi/Substance/Marmoset-packed masks drop in without re-authoring. The ChannelPick helper wires the choice through every consumer (parallax raymarch, BRDF shadow trace, surface metallic/smoothness, AO, height) so the choice is honored everywhere.
  • Multi-Region Mask + Secondary Emission + Dual MatCap: _RegionMask with independent R/G/B zone tints and emission boosts lets authors paint hard-edged feature zones without a second material. A full secondary emission layer with its own map, mask channel, AudioLink band, and intensity routes bass to one circuitry layer and treble to another. Two complete matcap layers with per-layer mask channel, tint, intensity, rotation, and blend mode (Add/Replace/Multiply).
  • Light Volumes Deep Integration: Full LV stack instead of a single slider - independent specular mix, dominant-light mode, clearcoat-specific specular, normal-bias offset (fixes edge bleed), manual world-space position offset, additive-only mode, and an opt-in Bakery L1 deringed-probe fallback for non-LV worlds. VRSL integration mimics a 13-channel Moving Head fixture and geo-warps the tessellated mesh via DMX Pan/Tilt - new _VRSL_Color_Hijack lerps the AudioLink color toward live DMX RGB without disabling FFT-driven color movement.
