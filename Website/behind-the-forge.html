Vixens Toolbox 2.18.1: now it loads on Linux and macOS

Status: Released

If you opened the toolbox in a Linux or macOS editor, none of the tools loaded, just a wall of "are you missing an assembly reference?" errors. Thanks to the Linux user who told us! This patch gets everything loading there, and the few tools that need ImageMagick tell you why they're switched off.

Linux and macOS editors

  • Quest conversion still shrinks your textures, using Max Size instead of resizing the image file.
  • Nothing changes on Windows.

Where this is at

  • If anything still breaks on Linux or macOS, tell us and we'll fix it.
Dev Notes Vixens Toolbox September 23, 2026

Vixens Toolbox 2.18.0: find out what is slowing your editor down

Status: Released

An hour into a session the editor starts crawling, and there is no way to tell whether the Scene view is redrawing nonstop or a tool left a heap of textures behind. This release gives you two tools to find out, moves the World Engine's performance map into the World Engine itself, and brings ImageMagick up to date with 25 upstream security fixes.

Scene View Enhancer

Under VixenTools > Unity Engine > Scene View Enhancer, in world and avatar projects. Click it again to turn it off.

  • Caps the editor's frame rate while you are not touching anything, through Unity's own Interaction Mode setting. Turning it off puts your own setting back.
  • Turning it on opens the Vixen Scene Stats panel in the Scene view: Scene redraws a second, the Editor frame cap, Script memory, Engine memory and Graphics driver memory.
  • Set the cap with the panel's Cap slider, anywhere from 30 to 240.
  • Close to 0 redraws while nothing moves is normal. A high number while your hands are off the mouse means something keeps redrawing the Scene view.
  • Free Unused and Memory Diagnostics buttons sit right in the panel.

Memory Diagnostics

Under VixenTools > Unity Engine > Memory Diagnostics, or on the Hub's Universal Utilities grid.

  • Leak Check: press Take Snapshot, repeat the task you want to test a few times (a bake, a texture pack, a material lock), press Free Unused Memory, then Compare With Snapshot. The rows that grew are what a tool left behind.
  • Only textures, materials and meshes that are not saved in your project count, so loaded assets never show up as leaks.
  • Largest Textures: press Scan Textures for the 50 textures using the most editor memory. The ones made at runtime are marked Not saved. Unity makes a few of its own, like its shadow map, but a big one from a tool is worth a look.
  • Select on any row selects it, and shows you where it lives if it is a saved asset.

The performance map is a tab now

Under VixenTools > Scene > Vixen World Engine.

  • FINDINGS and PERFORMANCE MAP sit side by side, and one scan fills both. No more second window popping up after every scan.
  • The compute score stopped counting things that cost nothing: baked reflection probes, and cameras with their Culling Mask set to Nothing.

Checks that had stopped working

When a package renames something, a World Engine check that looks for it by name goes quiet and tells nobody. We went back through the packages it supports, release by release, and found five that had. Then we rebuilt the texture checks so no fix ever rewrites your image files, taught the Udon checks to count what really runs every frame, and brought ImageMagick up to date.

  • ProTV 3 split its speakers into two lists, so the AudioLink link check and the 3D speaker distance check found nothing. Both read the new lists.
  • ProTV 3's new audio adapter is checked, and the missing AudioLink warning stays quiet when you switched AudioLink off on the adapter.
  • TXL 2 moved AudioLink onto the Audio Manager. The check looks there now, with a one-click fix.
  • The check for LTCGI screens that take their colour from AudioLink, in a scene with no AudioLink, never actually ran before. It does now.
  • The UdonSharp sync mode check was looking in the wrong place, so it found nothing either.
  • Older versions of every one of these packages are still checked the old way.

Texture fixes that leave your files alone

  • The texture checks now work the way the VixForge Texture Check does: every fix changes import settings, and nothing rewrites your image files any more.
  • A texture that imports bigger than your target gets a lower Max Size. Before, the file itself was overwritten at the smaller size, and the fix could even raise Max Size.
  • New findings: normal maps not on BC5, mipmaps off, the wrong colour space for a slot, a normal map imported as a colour texture, and bent normal maps bigger than they need to be.
  • A fix that makes a texture bigger in memory says so, and Toggle All Fixes leaves it for you to tick.
  • Convert To PNG copies PSD, JPG and big TIF, TGA or BMP files to Assets/VixenTools/Converted/, with the same import settings, and points your materials at the copy. The original stays exactly where it was.
  • The big file check is gone. VRChat never sees your source file, only what Unity imports from it.

Udon checks that count the right thing

  • The heavy script check added up every instruction in a script, so TXL's player controls, playlist queue and audio manager were flagged, though none of them runs anything every frame.
  • It now counts only what Update, LateUpdate and the other every-frame events can reach, times the number of objects running the script.
  • Continuous sync is only flagged when a script has synced variables, and a pickup or Rigidbody above or below it now counts. AudioLink's controller stops showing up.
  • Findings show which objects a nested object sits under, so two with the same name can be told apart.
  • The player data check only fires when saving can happen every frame.

A safer ImageMagick

  • Updated to ImageMagick 7.1.2-31. Among its 25 security fixes are two code injection flaws in text labels, which Badge Studio uses to draw your badge text.
  • ImageMagick now only works with what the toolbox needs. Script formats, PostScript and PDF, web addresses, the clipboard and screenshots are blocked, and so are a set of rarely used formats that had recent security fixes.
  • It can no longer start any other program, and it refuses images wider or taller than 32,768 pixels.
  • Every texture format Unity imports is still allowed.

Where this is at

  • Everything above is in, and tested in Unity release.
  • ImageMagick has fixed more since 7.1.2-31, and those fixes are not in a Magick.NET release yet. We will update again as soon as they are.
Dev Notes Latex Ultra Toon Clothing Pro Fur Pro World Surface World Fur September 18, 2026

Latex Ultra, Toon, Clothing Pro, Fur Pro, World Surface and World Fur: the music reaches every layer now.

Until now the music could light your emission, pump your mesh and not a lot else. This update gives every emission layer its own way to react, makes your outlines move with the beat, and adds a new effect drawn from the patterns sand makes on a speaker. It all starts switched off, so nothing changes until you go looking.

Cymatics

Under SPECIAL EFFECTS.

  • Draws, in light, the figures sand makes on a singing metal plate. The music picks the figure, so it changes shape as a track moves from the kick to the hats.
  • A loud passage shakes the sand about until it settles again.
  • Pick a Style, then use Depth to stack plates down into the surface. With no music it drifts between figures on its own.

Music Reactions

On each layer under EMISSIONS.

  • Note Trigger lights a layer only while its note is playing.
  • Beat Strobe flashes it on each hit and leaves it dark in between.
  • Waveform Warp bends its pattern with the live sound wave, like the trace on an oscilloscope.
  • Layers 2 to 5 also get the AudioLink Color Blend that layer 1 already had.

Outlines that move with the music

Under each outline in OUTLINES.

  • Music Colour tints the line, and Travelling Pulse runs each beat along it.
  • Beat Reveal keeps the line hidden until a beat pushes it out.
  • Equaliser Silhouette turns the line into an equaliser drawn up your body.

A few more

  • Speaker Glow under Sonar: the side of you facing the speakers glows with the beat, with a rim along your edges.
  • Drop Burst under Vertex Fracture: a big peak bursts you into shards, and you pull back together as it passes.
  • Body Equaliser under Vertex Pump lays the music up your body, bass at your feet and treble at your head, so each part swells with its own slice of the sound. The world shaders call it Height Equaliser.
  • Notes glitter colour: every flake takes one of the notes AudioLink hears, so the glitter shows the chord being played.

Native Touch

Under Touch.

  • Touch finds hands on its own, from what the camera already sees. No contacts, no animator.
  • Hands dent the goo and push the water aside. Each person sees only their own touches, up close, and never in a mirror.
  • Touch is its own group now, so a wet-only material can use it too. The idea comes from Warren's Fast Fur.

Movement

Under Movement.

  • The goo sloshes behind you, the wet streaks sweep back and the drops trail behind you. Land a jump and the goo wobbles and shakes drops loose.
  • VixenTools > VixForge Editor > Wet and Goo Movement Setup builds the animator layer for you from the VRChat Velocity and Grounded parameters.

Oobleck Dance

Under Goo Effects.

  • Like cornstarch on a speaker: on the beat the goo stands up into fingers along a sand-plate figure, and slumps back when the music stops.

More music for the wet and the goo

  • Travelling Beats runs each hit down the wet streaks and along the goo veins.
  • Music Colour tints the water, the veins and the drops.
  • Beat Shake-off throws a shower of drops loose on a big peak. Beat Writhe, Beat Reach and Beat Drops make the goo writhe harder, fling the Cling strands further and swell the hanging drops.

Water that acts like water

Under Wet Effects.

  • Gravity Pooling gathers water on the parts of you that face up.
  • Touch Wipe clears it aside where you're touched.
  • Glints put tiny sparkles in the water and on the drops.
  • The drops and the Cling strands take the room's light now, so they don't glow in a dark world.

Masks and viewers

  • Extra Mask borrows an Emission layer map or a Matcap mask as a second mask for the wet and the goo, at no texture cost.
  • Also Apply To Wet And Goo under Viewer Context can show them only in a mirror, only in photos or only up close.

Separate Maps

Under SURFACE.

  • Metallic and smoothness can come from their own textures now, not only the Packed PBR Mask. Tick Use Metallic Map or Use Smoothness Map and drop the texture in.
  • Got a roughness map? Tick Map is Roughness.
  • Global Metallic and Global Smoothness still scale them, so raise those to see the whole map.

Set Up for Toon Standard Specular Map

Under Channel Mapping.

  • One click reads a Substance ToonStandardSpecular export: metallic from red, smoothness from green, occlusion from blue.
  • With the slot empty, it finds that file next to your Albedo and drops it in.

Channels pick themselves

  • Drop a texture into a slot with a channel picker, like Occlusion Map or Height Map, and the picker moves to the channel that holds the data. An occlusion map stored in green just works.
  • It only changes when the answer is clear, and the Console tells you what it set.
  • The Packed PBR Mask builder packs occlusion and height too, only uses the files that match your Albedo's name, and offers a finished map it finds before building a new one.

Unity on Linux

  • The shaders now run in the OpenGL and Vulkan editors that Unity uses on Linux, so you can see and set up your materials there.

Light Volumes for outlines and shards

Under Vertex Fracture and each outline's Lighting.

  • Outlines and fracture shards took their light from the light probes only, so they could look darker than you in a Light Volumes world.
  • Raise Shard Light Volumes, or the Light Volumes slider on an outline. Both start at 0.

Fixed

A round of fixes that came out of testing, plus everything that looks different once you update.

  • Touch could throw parts of the mesh out in long spikes, most of all on a mesh imported at 100 times scale. Depth is in metres now, as its tooltip always said.
  • Tessellation Detail was hidden, and did nothing, unless the goo sagged. It now works whenever Goo Effects, Touch or Kinetic Modules is on.
  • Vertex Fracture shards ignored Global Metallic and Global Smoothness, so on a material with no packed map they came out nearly black.
  • Follow PBR Map under Real Fur ignored Channel is Roughness and Invert Metallic, so with a roughness map the roughest hairs shone the most.
  • Real Fur follows the Light Volumes V3 controls. Turning Intensity down used to fade the coat toward black.
  • Smoother Probe Lighting could pick up the wrong light in worlds made with the first version of Light Volumes.
  • An effect could not borrow a mask from an Emission layer or a Matcap you had switched off. Borrowing reads that layer's map, not its glow, so you can park a map on a layer you never light and mask from it now.

Before you update

  • Per-Light Specular is off by default, not on as the last notes said. If you raised Specular Mix because of that note and Per-Light Specular is off on your material, set it back.
  • Drops and Cling strands now take the room's light, so they can look darker in a dim world. Room Lighting at 0 brings the old look back.
  • Vertex Fracture shards now follow Global Metallic and Global Smoothness. If you tuned your shard colours around the old look, check them again.
  • Real Fur highlights with Follow PBR Map on now follow Global Smoothness and Global Metallic, so they can look dimmer. Raise Strand Specular under Surface Fur to bring them back up.
  • On World Surface and World Fur, lightmapped surfaces no longer take highlights from a world's base Light Volumes. If a lightmapped floor looks less glossy, raise Specular Mix under Light Volumes V3.
  • If you turned Depth under Touch right down to make up for a scaled mesh, turn it back up.
  • Borrowed masks hold again, so an effect that was quietly covering your whole material will snap back to its map. Go through Mask Source and Invert Mask on each effect you have masked, and set Mask Source to None on anything you meant to leave unmasked.

The melt moves now

Under Goo Effects > Melt.

  • Beat Sag pulls the goo further down you on the hit, Beat Stretch draws it thinner as it goes, and Beat Variation breaks up the edge so it does not run as one sheet.
  • Beat Underside thickens what hangs beneath you.
  • Beat Flow adds to the clock rather than scaling it, so the goo gathers pace on a busy passage and settles again without ever jumping.

And so does everything else

Under Goo Effects, each one beneath the slider it drives.

  • Beat Depth surges the writhe itself, so the tendrils stretch on the hit instead of only running faster. Beat Sway swings the hanging strands wider.
  • Beat Melt and Beat Pooling send the goo toward the floor and spread the pool where it lands. Beat Formation pushes the wavefront up, so the gear builds itself in time with the track.
  • Beat Gloss, Beat Coat, Beat Absorption and Beat Refraction work the slime itself, from a wet flash on the beat to the colour sinking deeper into it.
  • Veins, Drips and Cling each got the same treatment, down to the speed of a single vein pulse.
  • Every one of them starts at zero, so the goo you have today looks the same until you reach for one.

Cybernetic Overlays moved

Under SPECIAL EFFECTS.

  • It used to sit in the middle of AUDIOLINK, a long way from the other effects. It is the last group under SPECIAL EFFECTS now.
  • Everything inside it is exactly as it was, and it still shows only while AudioLink is on.

Lighter locked materials

  • Locking used to keep every setting of every feature, whether you had it switched on or not. Now it keeps only what you use.
  • Matcaps, Wet Effects, Goo Effects, Glitter, the outlines, Car Paint, Viewer Context, Flipbook and every effect under SPECIAL EFFECTS drop out when they are off. On a material using none of them that is around 460 settings gone.
  • Glitter layers 2 to 5 used to ride along even when switched off. Only the layers you use are kept now.
  • Locking no longer prints a shader warning for every material, and all 44 texture slots across the six shaders now tell you what they are for.

Biofeedback

Under SPECIAL EFFECTS.

  • A heartbeat from the bass, Tension from the mids and a Spike from the treble, with a slow Breath laid over the top so it never sits perfectly still.
  • It has always driven four things with no way to see or stop it: your subsurface glow, the light coming through your thin parts, the AudioLink Color Blend hue, and Emission layer 1. Each of those has its own slider now.
  • Every one of them starts exactly where the pulse has always run, so nothing about your material changes until you move one. Enable turns the lot off if you never wanted it.

Thickness

Under Subsurface.

  • How thick your material is where light soaks through was the pulse and nothing else. There was no control for it at all.
  • There is a Thickness slider and a Thickness Map for it now, and Subsurface under Biofeedback decides how far the pulse moves it on top.
  • Left at 0 it looks exactly as it does today.

Where this is at

  • All six shaders build clean: no errors, no warnings.
  • Everything across these six parts is going through testing on avatars now. None of it is out yet.
  • Next: the test pass, then the release for all six shaders.
Release Notes World Surface World Fur September 14, 2026

World Surface and World Fur are out: the avatar shaders, built for the room around you.

World Surface

Every shader we've made so far was for the avatar. Walk that avatar into a world and it stands on a floor, next to a wall, under a screen, and none of those know about the lighting it uses. World Surface and World Fur put the same lighting, the same effects and the same inspector on everything else in the scene.

  • For the things a world is made of: tile, glass, a bath tub, painted walls, polished floors, a sofa.
  • It's the Toon shader with Wet Effects and Goo Effects from Latex Ultra and the cloth sheen from Clothing Pro. Water beads and runs down tile, and goo pools on the floor.
  • The shading styles, matcaps, Car Paint, glitter, emissions, decals, outlines and special effects all come across.

World Fur

  • Real standing strands for carpets, shaggy rugs, moss over stone and grass across a field, with a pile you can see from the side.
  • Length and Density set the coat, Tufting clumps it, and Droop and Wind Sway make it hang and move. Keep Strands Per Face and Curve Segments as low as still looks good.
  • Surface Fur fills in underneath, so the pile doesn't thin out to bare floor when you look straight down.

Your bake, read and lit

Under Baked Lighting.

  • Press Generate Lighting and the shader uses the result. Directional lightmaps keep your normal maps catching the light, and shadowmask lets baked and real-time shadows sit together.
  • Set Global Illumination to Baked and a glowing material becomes a light in the bake. Emitted Light sets how bright, without changing how it looks on screen.
  • Smooth Filter stops a low resolution bake looking blocky, and Highlight lets baked light throw a highlight on a polished floor.

World Lighting Check

Under VixenTools > VixForge Editor.

  • Tells you when a material's Realtime Global Illumination toggle and your scene's Lighting settings disagree, and sets them right in one click.

Every light in the world

  • LTCGI, Light Volumes, VRSL and AudioLink, running together. LTCGI changes the most: your screens and neon signs become real area lights.
  • Lighting Check, under DEBUG TOOLS, paints the surface with the light actually reaching it. Set it back to Off before you upload.

Where this is at

  • Both are out today as 1.0.0.
  • To celebrate 3,500 Vixens Toolbox downloads, the whole shader package, World Surface and World Fur included, is free for everyone until September 21. Grab it from the give away post in the Discord.
Release Notes September 12, 2026

Lighting that holds its shape, fur that casts its own shadow, and every reactive control moved in beside the thing it drives.

You know all three of these. A material lit only by light probes goes flat and grey on the side away from the light. A low poly mesh draws its shadow edge as a jagged line along its own facets. Goo running onto the floor breaks into hard edged patches instead of spreading. We went after all three.

Sharper Probes

Under Lighting.

  • Light probes are stored in a way that flattens out and goes grey on the side facing away from the light. This reads them differently, so the shape of the light survives.
  • The room does not get brighter. The total is identical, it just stops being smeared into a flat wash.
  • It starts off, so nothing changes until you turn it on.

Soften Terminator and Shadow Normal Bias

Two new controls under Shadow Detail.

  • Soften Terminator smooths the line between lit and unlit. On a low poly mesh with smoothed normals that line runs along the facets and reads as jagged, and this turns it into a gradient.
  • It widens that line rather than just dimming it, the way a big soft light does.
  • Shadow Normal Bias lifts a mesh off its own shadow, for when one object needs more than the scene light is giving everything else.
  • Both start at 0.

Goo that pools

Under Goo Effects.

  • Goo hitting the floor used to split into hard edged patches. Three things were doing it, and the worst was that the spread direction was picked per noise cell, so neighbouring parts of one strand got shoved opposite ways.
  • It spreads smoothly now, and the new Pool Softness slider sets how rounded the join is where a strand meets the pool.
  • The same jumpiness was scaling how far every strand stretched, so goo reads smoother everywhere, not only on the ground.

Fur that joins in with the lighting

Under Real Fur.

  • Grown strands took no shadows at all, so a coat standing in the shade of a wall stayed bright while the body underneath went dark. They read the same shadows the body does now.
  • They cast shadows too. A coat throws a shadow of its own shape instead of the body casting a bare silhouette straight through it. Point lights are the one exception and still see only the body.
  • The new Follow PBR Map slider lets your packed map set how shiny each hair is, so fur over a glossy patch catches more light than fur over a matte one. It starts at 0.

AudioLink moved in with the controls it drives

Right under each control, and only while AudioLink is on.

  • The Band and amount for a reactive feature used to sit together in the AudioLink section, a long way from the slider they actually affect. Each pair now sits directly under its own control.
  • Seven more things can react, depending on which shader you are on: Baked Shadow Map, Micro Detail, Transmission, Car Paint, Fabric, Surface Fur and Rim Light.
  • Flipbook drives the playback rate, so a sheet skips forward as the beat moves it rather than rolling on at its own pace.
  • Every one of them starts at 0, so nothing reacts until you ask it to.

Fixed without you touching a thing

  • Clearcoat was reflecting a sharper version of the room than the surface underneath it. The two match now.
  • Light Probe Proxy Volumes were ignored outright. A large object set to use one took a single probe reading for the whole mesh.
  • Parallax detail shimmered in the distance, because the height map was read at full resolution on every step however far away the surface was.
  • Fabric sheen reflected about half the room it should have at high Roughness (soft to velvet). It is measured properly now instead of estimated.
  • Tessellation Detail did nothing unless something was moving the surface, and nothing said so. It only appears now when something is.

The Lighting section, rebuilt

Under Lighting.

  • Rim Light, Subsurface, Transmission, Anisotropy and Specular Response each have their own group now, so you are not hunting down a flat list for the one slider you want.
  • Every control in the section has a tooltip. Hover it and it tells you what it does.
  • Labels dropped the word their group already says, so Rim Light Strength is just Strength inside Rim Light.
  • The rim was built from your viewing angle and nothing else, so it glowed the same all the way round your outline whether the light was behind you or square in front of you. That is how a hard highlight behaves, not an edge light. Follow Light ties it to the light in the room, and Wrap sets how far round the form it carries. It starts at 0, so nothing changes until you turn it up.
  • Rim Light Strength read 0 to 5 while the shader clamped it at 1, so four fifths of the slider did nothing. It reads 0 to 1 now and looks identical.
  • Anisotropy only shows while Polish is on, which is the only time it has ever done anything.

Every control has a tooltip

Everywhere.

  • All 1320 of them, across every section, not just the ones that had picked one up over the years.
  • Hover anything and it tells you what it does and what the numbers mean, in plain language rather than in shader terms.
  • The only four without one are the credit lines for AudioLink, VRSL and Hyperspace, which are not controls.

Lightmap UV Fix

Under VixenTools > VixForge Mesh Fixes.

  • Finds the models behind Unity's overlapping UVs warning and sets their lightmap UVs up for the resolution your scene actually bakes at.
  • It starts with only the objects Unity has flagged, and widens to every FBX in the project, or to whatever you have selected.
  • Read resolution from the scene fills the number in from your Lighting window.
  • Models that came in with a package get fixed too, which is usually where broken lightmap UVs arrive from in the first place.
  • You see the whole list before anything changes, and nothing is touched until you press the button.

Switchboard

Under VixenTools > VixForge Editor.

  • Every toggle on every VixForge material in your scene, one row each, with a count of how many materials have it switched on.
  • Turn one on or off across the whole room in a click, or press Select to pick out the materials carrying it.
  • Point it at your selection instead of the scene when you only want part of the room.
  • Locked materials are counted and left alone, because a locked material has its toggles baked into its own shader.

The rim takes light from wherever it actually is

Under Lighting > Rim Light.

  • Five sliders decide how much the scene lights, the ambient, a Light Volume, an LTCGI screen and a VRSL rig each feed the edge.
  • LTCGI and the stage rig did not reach it at all before, so a material stood in front of a bright screen still wore an edge lit by the room behind it. Both start at 0.
  • Follow Light had nothing to follow in a room with no scene light, so the edge landed wherever Unity happened to leave the light slot pointing. It steers by the volume's own direction now.

Fracture

Under Lighting > Transmission.

  • Hold a hand up to the sun and the light does not come through evenly. It comes through as rays that find the gaps between your fingers, bright where they got a thin path and dark where a knuckle blocked them.
  • This makes the glow follow the detail in your height source the same way, and each shaft stretches along the light instead of spreading out evenly.
  • Spread sets how soft the edges are. Low gives hard rays from a small bright source, high gives the wash you get on an overcast day.
  • Starts at 0, which is the flat glow you have now.

The creases see the whole room

Under Lighting > Cavity Lighting.

  • Cavity Lighting reached the scene lights and the ambient and stopped there, so in a room lit only by volumes the creases sat flat however the light moved.
  • Three new sliders for Light Volumes, LTCGI and VRSL, each starting at 0.

Point Light Strength

Under Light Volumes V3.

  • A point light placed in a world arrived welded to the baked volumes, so the only handle on it was the Light Volumes strength, and that pulls every volume in the room down with it.
  • This moves the point lights on their own. 1 leaves them exactly as the world author placed them, 0 takes them out.

Shading gets its falloff back

Under Shadow Detail.

  • Shadow Hardness shipped set to 1, and at 1 the old maths flattened the whole lit side of a material to full brightness. The normal fade from light into shade was simply gone, on every material, out of the box.
  • It fades properly now, and new materials start at 0. Your existing ones still have it stored at 1, so set it to 0 for realistic shading.
  • It was also being applied to your highlights, so turning it up spread the highlight across everything lit. Highlights use the true angle now, the way Unity's own lighting does.
  • Subsurface was being handed that flattened value too, which left it nothing to work with. It reads the true angle now.

Before you update

Nearly everything in this release starts at your old values, so a material looks the way it did until you go looking. These are the exceptions: fixes that change how a material you already have looks, each with the setting that takes it back.

  • Shadow Hardness under Shadow Detail is still stored at 1 on existing materials, and 1 brightens the lit side well above normal. Set it to 0 for realistic shading. New materials start at 0.
  • A locked material only changes the values you mark. Right-click each value an animation or a VRCFury toggle should change, tick Animated (when locked), and lock again.
  • Strength under Lighting > Transmission was being applied twice. A mid setting is now close to twice as strong, so a material at 0.5 wants 0.25 for the old look.
  • An emission layer switched on with an empty map slot now glows. Untick Enable Layer 1 (or 2 to 5) on any layer you did not mean to use.
  • Point light highlights from Light Volumes were added twice and are softer now. Raise Specular Mix under Light Volumes V3 if you liked them brighter.
  • Clearcoat reflections are a little softer, so the coat agrees with the surface under it. Nudge Clearcoat Smoothness up for the old sharpness.
  • A rim on metal takes the metal's colour instead of a flat grey haze. Pull Strength under Rim Light down if a metal material now reads too strong.
  • Rough metal is a little brighter with Polish off. Untick Multi-Scatter Compensation under Lighting > Specular Response for the darker look.
  • Goo landing on the floor spreads smoothly. Pool Softness under Collision at 0 gives you the old hard landing.
  • Goo can glow through on its own now. Set Translucency under Goo Effects to 0 if you do not want it.
  • A Polish mask painted to black no longer lets the rim, subsurface and transmission through at full strength.

Glitter with a style of its own

Under SPECIAL EFFECTS > Glitter.

Under VixenTools > Avatars > Optimization Suite.

A whole new shader for fur, and real grown strands in Clothing Pro

Fur that lives only in the lighting looks great head on and vanishes the moment you see it from the side. There is nothing there to catch the light, because there is nothing there. So we grew some.

Fur Pro, a new shader

Assign VixForge / Fur Pro to a material and set up BASE, NORMAL MAPS and SURFACE exactly as you would on any of the others.

Real Fur

Its own group under Special Effects, directly below Surface Fur. In Fur Pro and Clothing Pro both.

  • Real hairs, grown as geometry. Every one is a single continuous strand from root to tip, so it holds up close, from the side, and at any length.
  • Strands Per Face grows hairs from each triangle of your mesh, Length takes it from short pile to a full coat, and Curve Segments sets how smoothly a long hair bends.
  • Strand Width and Tip Taper shape each hair. Hairs always come to a point, and nothing ever falls below a pixel on screen, so fine fur will not sparkle at distance.
  • Tufting clumps nearby hairs into locks the way real fur parts. Guard Hairs mixes longer strays over the short coat, so the outline breaks up instead of ending on one clean edge.
  • Comb Bend lays the coat over, Droop lets the tips fall under their own weight, and Wind Sway with Wind Speed keeps it moving.
  • Self Shadowing has the hairs shadow each other, so the coat opens up and closes down as the light moves around it. This is most of what gives fur its depth.
  • Shade Variation gives every hair its own slightly different colour. Backlight it and the tips glow, because light passes straight through a thin fibre.
  • Root Shading darkens the base, Coverage thins the coat to bald patches or packs it solid, and Tip Softness stops it ending on a hard edge.

Mesh Detail

Second control in the Real Fur group.

  • Splits your triangles into smaller ones before growing hairs, so you are not limited by how dense your mesh is.
  • 2 is about four times the hairs. 4 is about sixteen.
  • It is the most expensive control in the shader, so raise it one step at a time and watch your framerate.
  • It only spends the detail on triangles that are big on screen, so distance stays cheap. Off by default.

Masks for the things that had none

  • Viewer Context > Mask keeps the mirror, photo and distance tricks on one patch and leaves the rest of the material alone.
