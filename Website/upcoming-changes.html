Upcoming Changes

What is coming in the next release, written as it stands today. Nothing here has shipped yet, so any of it may still change before it does. Everything already released is on the Shader Changelogs page.

VixForge Editor 2.1.0 - Unreleased

A builder for the new Packed Atlas matcaps, copy and paste for every stacked layer in the shader, and the tools all put where you can find them.

Added

  • Matcap Atlas Builder. Under VixenTools > VixForge Editor, and on the Build Atlas In Unity button inside any matcap layer's Packed Atlas panel. Drop a matcap into each cell of the grid and it lays the sheet out, saves it, imports it as colour, and fills in Source, Grid and Sections on the material.
  • Copy a layer onto another one. Copy Layer and Paste Layer, at the top of every matcap, decal, glitter layer and emission layer. Copy takes everything that layer has, textures included, and Paste writes it onto whichever layer you press it on. It works across materials, so a second piece of gear is two clicks. It carries the Animated marks with it, so a layer you drive from a clip does not quietly lose them. Anything shared by the whole section is left alone: Projection on the matcaps, the whole-effect controls in Glitter Layer 1, the group's own mask.
  • The tools are on the Hub. A row of buttons under Lock and Unlock opens Texture Check, World Lighting Check, the Matcap Atlas Builder, Texture Packer, the Cross Shader Editor, Scan for Quad Meshes, Bake Outline Normals, the Material Lock Manager and Settings. Several of these had only ever been in the menu bar. Each button says what its tool is for when you hover it, and How To Use now lists all of them.
  • World Lighting Check now fixes the old Light Volumes settings. Point lights in a world used to shade your material off the bare mesh instead of your normal map, because two settings shipped at the wrong values. New materials are already right; this finds the ones you already have and sets both in one go. It only touches materials still sitting on the old values, so anything you tuned by hand is left alone, and Undo puts it back.
  • A Preview button on the Matcap Atlas Builder, on both tabs, so you can see the sheet or the section map before it writes a file.
  • It builds the section mask too. Give the second tab one black and white mask per section and it combines them into a single map, working out the exact grey level each section needs. The map carries the section in R and the coverage in G, so one texture says which matcap a spot takes and whether the matcap shows there at all, and the builder points Section Channel and Mask Channel at the right ones. If you would rather paint the map yourself, each row lists its 0 to 255 value.

Changed

  • Texture Check no longer changes compression. It still tells you which textures are uncompressed and what they cost, because that is the biggest saving on most avatars. Setting it stays yours: the right format depends on whether the texture carries alpha, and getting that wrong doubles the memory instead of halving it.
  • Locking says what it removed, not what it did not. The line read "removed 0 unused properties" on a material that had nothing to remove, which looked like a failure. Zero is the right answer there: that pass only clears leftovers from a shader the material used to be on.
  • Texture Check asks before it fixes. Fix All rewrites import settings on your own textures and Ctrl+Z does not put an import setting back, so it now says what it is about to change and waits. When it finishes, the full list goes to the console.
  • The long scans show progress and can be stopped. World Lighting Check reads every material in the project, and Texture Check reads every texture on the avatar. Both used to go quiet for as long as it took.
  • Right-click a property and the locking help is ours. It opens How To Use in the Hub, which now has a short section on what locking does to a property an animation drives.

Removed

  • The Install VRChat Asset Installer button in Settings. It installed a package from another author into your project. Nothing else changes, and the tool is still there in VCC if you use it.

Fixed

  • The package now imports on Unity 2019.4. A dozen editor calls reached for things only newer Unity has, and each one stopped the import dead. Nothing changes on 2022.
  • A VRChat world project now compiles. Installing into one filled the console with errors: the Director could not find Udon, and three pieces of the editor took the base SDK being installed to mean the avatar SDK was too. Each now tests for what it actually needs.
  • Eight errors on a first install. The Shader Translator's window layouts still pointed at the folder layout of the editor this one was forked from, so a fresh project could not find their stylesheets and the windows came up unstyled.
  • Locking sweeps material-swap clips in a project that has both SDKs. That sweep switched itself off in anything that looked like a world project, which included an avatar project with the world SDK sitting alongside.
  • The Hub stylesheet imports without warnings on older Unity. Five hover fade timings were rejected and ignored there. Buttons still light up on hover, just without the fade.
  • Texture Check could make an avatar heavier, by a lot. Fix All applied three things that raise texture memory: switching mipmaps on adds a third, and moving a normal map to BC5 doubles it if it was on a 4 bit format. The window leads with your memory total, so a batch that raised it was the one thing it should never do. Fix All now only does what cannot make you heavier, and the rest are one row at a time with the cost written on them.
  • The tool windows keep what you put in them. Anything that makes Unity recompile emptied them, so eight matcaps dragged into the Atlas Builder grid could vanish while you were still working. The grid, the scan reports and the settings all survive it now.
  • The read-me inside the editor folder was the one from the project this inspector was forked from. It named a different product and linked to a different Discord.
VixForge / Toon 2.1.0 - Unreleased

The matcaps, rebuilt. Five layers that each did one thing now do everything a layer can do: how the image gets wrapped on you, what fades it, what colour it comes out, and whether it changes the material underneath. Two of them need no image at all.

Heads up

  • Two sliders to change on materials you already have. Under Light Volumes V3, set Normal Stability to 0 and Point Light Shading to 3. They shipped at 1 and 1, which had point lights in a world ignore your normal map and light the surface off the bare mesh instead. New materials come with the corrected values.

Added

  • Channel Mode picker for VRSL. Under Stage Lighting & VRSL, next to DMX Base Channel. Match it to the Channel Mode on your VRSL fixture and the material reads the right channels: 1CH, 4CH, 5CH or 13CH. It tells you which channel is which when you hover it. New materials default to 13CH, which is what VRSL's moving heads use.
  • Every layer picks how it is wrapped on you. Mode, under Projection. View is the look you already have. Skew Free stops the image stretching toward the edge of the screen. Reflection tracks the way real chrome does. Fresnel Ramp reads the image left to right by viewing angle, so a plain gradient becomes a rim light. Light Direction turns it with the world light instead of with your head, and Screen pins it to the camera.
  • Normal Follow. Matcaps have always ignored your normal map, so they sat flat over your surface detail and read as paint. Turn this up and the matcap follows every bump. It starts at 0, which is exactly how your material looks now, so nothing moves until you move it. Normal picks what it follows: your normal map and detail, the bent normal so the matcap darkens where the shape closes in, or the raw mesh.
  • Packed Atlas. One texture holds up to eight matcaps in a grid and a mask picks which one shows where, so a material carries a whole set without carrying a whole set of textures. Build Atlas In Unity, in the layer's Packed Atlas panel, does the work: drop a matcap into each cell and it lays the sheet out, saves it, imports it and fills in Source, Grid and Sections for you. It builds the mask too, from one black and white mask per section, so there is no grey level to work out by hand. Every cell gets its own Tint, Intensity, Emission, Lit Mix and Opacity under Atlas Sections, shared by every layer in Atlas mode.
  • Procedural matcaps, no image at all. Studio Rig builds a lit sphere with a key light, a fill and a rim, which is what most matcap images are painted to imitate in the first place. Liquid Flow churns, Shatter reads as broken foil with flat facets and cracks between them, Iridescent Film sweeps the spectrum with your viewing angle, and Plasma and Caustics are moving light patterns. Colour A and B set the palette, and Scale, Speed, Sharpness and Warp shape it.
  • Depth. Sinks a layer below the surface so it slides against you as you move your head, the way flake does under a clear coat. Give two layers different Depth and they read as suspended in something thick.
  • A matcap can set the material, not just the colour. Smoothness Push, Metallic Push and Clearcoat Push, under Surface. Mask one and a part of you goes wet-looking or metal while the rest stays as it was. These change the light on the material, so they show in every blend mode except Replace, which covers that light up. Use Base Colour if you want the matcap to take the surface over and still catch highlights.
  • Eight more blend modes. Screen, Overlay, Soft Light, Subtract, Lighten, Darken and Boost join Add, Replace, Multiply and Car Paint. Boost brightens what is already there rather than adding a colour of its own.
  • Base Colour, the ninth, is the one to know about. Every other mode lands on the finished picture, so Replace paints over the light along with everything else. Base Colour paints the matcap on as the material itself and then lets the light fall on it, so the gear catches highlights and reads as something solid rather than as a sticker. It is also what makes the Surface sliders below do anything.
  • Three ways to fade a layer, all off unless you use them. Circle Mask fades the matcap out toward the rim of the sphere image so it lands as a soft round highlight. Angle Start and Angle End fade it in over a range of viewing angles, so Start 0.5 with End 1 gives a rim that only lights up at glancing angles. Fade Start and Fade End fade it out with distance in metres, for a strong chrome up close that calms down across a room.
  • A matcap can borrow a mask. Mask Source on every layer takes its shape from an emission layer or another matcap, so a layer needs no map of its own. Invert flips whichever mask it ends up using.
  • Two Tone. Remaps the image between a Shadow Colour and a Highlight Colour by brightness, so one plain grey matcap serves any palette.
  • Hue Shift, with a Hue Speed that drifts it on its own.
  • Albedo Mix tints the matcap by whatever is painted underneath, so it picks up your texture instead of sitting on top as one flat colour. Light Colour Mix tints it by the light in the room.
  • Emission. Feeds a matcap into the glow, so it blooms in a world that has bloom.
  • Blur. Softens the image, and Blur Channel reads a channel of the Mask to blur some places more than others. It costs nothing: it reads a smaller copy the texture already carries.
  • Zoom shows less of the sphere as you turn it up, and Mirror Flip flips the matcap left to right in a mirror so your reflection catches light from the same side you do.
  • AudioLink reaches more of each matcap. Alongside the Band and Intensity you had, each layer now drives its Emission, its Hue and its Scroll from the track.
  • Copy a layer onto another one. Copy Layer and Paste Layer now sit at the top of every decal, every glitter layer and every emission layer as well as every matcap. Copy takes everything that layer has, textures included, and Paste writes it onto whichever layer you press it on, on this material or another one. Anything belonging to the whole group is left alone, like the controls in Glitter Layer 1 that light all three layers.

Changed

  • The matcap controls are grouped. Projection, Movement, Offsets, Masking, Colour, Surface, Packed Atlas, Procedural and AudioLink each get their own panel, because each layer now carries nearly four times the controls it did. Tiling sits with Projection and Scroll sits under Movement.
  • All five layers carry the same controls. They were five separate copies of nearly the same code, so a feature had to be written five times to reach every layer. There is one layer now, used five times.

Fixed

  • AudioLink's waveform was only a sixteenth of itself. The waveform is 2048 samples stored across sixteen rows, and we were reading the first row only, so every effect driven by it saw the same short slice. It also came out shifted off centre. Both fixed, so the waveform effects now follow the whole sound.
  • VRSL was reading the wrong DMX channels for colour. The colour it picked up from a fixture came from that fixture's movement and dimmer channels instead of its red, green and blue, so the tint was wrong and shifted whenever the light moved. It now reads the right ones, and a fixture faded down no longer lights the material at full colour.
  • LTCGI was reading the wrong pixel in worlds that bake it. The shader ran LTCGI in its world mode, which looks up a baked lightmap an avatar does not have, so it read one stray pixel of the world and let that decide how much LTCGI the whole material got. It now runs in the avatar mode LTCGI ships for exactly this case.
  • A switched-off feature no longer rides along in a locked material. Its controls were being baked in even though its code was correctly stripped, so a material with LTCGI off still carried every LTCGI setting. Measured on one outfit material with 10 features on and 55 off: 1063 controls in the locked shader where there were 1558, so 495 fewer.
  • Fog no longer breaks the shader on older Unity. The fog code tested its keywords in a way that only worked on the passes that happened to declare them. Fog looks exactly as it did.

It builds the mask too, from one black and white mask per section, so there is no grey level to work out by hand. Every cell gets its own Tint, Intensity, Emission, Lit Mix and Opacity under Atlas Sections, shared by every layer in Atlas mode.
  • Procedural matcaps, no image at all. Studio Rig builds a lit sphere with a key light, a fill and a rim, which is what most matcap images are painted to imitate in the first place. Liquid Flow churns, Shatter reads as broken foil with flat facets and cracks between them, Iridescent Film sweeps the spectrum with your viewing angle, and Plasma and Caustics are moving light patterns. Colour A and B set the palette, and Scale, Speed, Sharpness and Warp shape it.
  • Depth. Sinks a layer below the surface so it slides against you as you move your head, the way flake does under a clear coat. Give two layers different Depth and they read as suspended in something thick.
  • A matcap can set the material, not just the colour. Smoothness Push, Metallic Push and Clearcoat Push, under Surface. Mask one and a part of you goes wet-looking or metal while the rest stays as it was. These change the light on the material, so they show in every blend mode except Replace, which covers that light up. Use Base Colour if you want the matcap to take the surface over and still catch highlights.
  • Eight more blend modes. Screen, Overlay, Soft Light, Subtract, Lighten, Darken and Boost join Add, Replace, Multiply and Car Paint. Boost brightens what is already there rather than adding a colour of its own.
  • Base Colour, the ninth, is the one to know about. Every other mode lands on the finished picture, so Replace paints over the light along with everything else. Base Colour paints the matcap on as the material itself and then lets the light fall on it, so the gear catches highlights and reads as something solid rather than as a sticker. It is also what makes the Surface sliders below do anything.
  • Three ways to fade a layer, all off unless you use them. Circle Mask fades the matcap out toward the rim of the sphere image so it lands as a soft round highlight. Angle Start and Angle End fade it in over a range of viewing angles, so Start 0.5 with End 1 gives a rim that only lights up at glancing angles. Fade Start and Fade End fade it out with distance in metres, for a strong chrome up close that calms down across a room.
  • A matcap can borrow a mask. Mask Source on every layer takes its shape from an emission layer or another matcap, so a layer needs no map of its own. Invert flips whichever mask it ends up using.
  • Two Tone. Remaps the image between a Shadow Colour and a Highlight Colour by brightness, so one plain grey matcap serves any palette.
  • Hue Shift, with a Hue Speed that drifts it on its own.
  • Albedo Mix tints the matcap by whatever is painted underneath, so it picks up your texture instead of sitting on top as one flat colour. Light Colour Mix tints it by the light in the room.
  • Emission. Feeds a matcap into the glow, so it blooms in a world that has bloom.
  • Blur. Softens the image, and Blur Channel reads a channel of the Mask to blur some places more than others. It costs nothing: it reads a smaller copy the texture already carries.
  • Zoom shows less of the sphere as you turn it up, and Mirror Flip flips the matcap left to right in a mirror so your reflection catches light from the same side you do.
  • AudioLink reaches more of each matcap. Alongside the Band and Intensity you had, each layer now drives its Emission, its Hue and its Scroll from the track.
  • Copy a layer onto another one. Copy Layer and Paste Layer now sit at the top of every decal, every glitter layer and every emission layer as well as every matcap. Copy takes everything that layer has, textures included, and Paste writes it onto whichever layer you press it on, on this material or another one. Anything belonging to the whole group is left alone, like the controls in Glitter Layer 1 that light all three layers.

Changed

  • The matcap controls are grouped. Projection, Movement, Offsets, Masking, Colour, Surface, Packed Atlas, Procedural and AudioLink each get their own panel, because each layer now carries nearly four times the controls it did. Tiling sits with Projection and Scroll sits under Movement.
  • All five layers carry the same controls. They were five separate copies of nearly the same code, so a feature had to be written five times to reach every layer. There is one layer now, used five times.

Fixed

  • AudioLink's waveform was only a sixteenth of itself. The waveform is 2048 samples stored across sixteen rows, and we were reading the first row only, so every effect driven by it saw the same short slice. It also came out shifted off centre. Both fixed, so the waveform effects now follow the whole sound.
  • VRSL was reading the wrong DMX channels for colour. The colour it picked up from a fixture came from that fixture's movement and dimmer channels instead of its red, green and blue, so the tint was wrong and shifted whenever the light moved. It now reads the right ones, and a fixture faded down no longer lights the material at full colour.
  • LTCGI was reading the wrong pixel in worlds that bake it. The shader ran LTCGI in its world mode, which looks up a baked lightmap an avatar does not have, so it read one stray pixel of the world and let that decide how much LTCGI the whole material got. It now runs in the avatar mode LTCGI ships for exactly this case.
  • A switched-off feature no longer rides along in a locked material. Its controls were being baked in even though its code was correctly stripped, so a material with LTCGI off still carried every LTCGI setting. Measured on one outfit material with 10 features on and 55 off: 1063 controls in the locked shader where there were 1612, so 549 fewer.
  • Fog no longer breaks the shader on older Unity. The fog code tested its keywords in a way that only worked on the passes that happened to declare them. Fog looks exactly as it did.
VixForge / World Surface 1.0.0 - Unreleased

A shader for the things a world is made of. Tile, glass, a bath tub, painted walls, polished floors, a sofa. It is the Toon shader with the wet and goo effects folded in from Latex Ultra and the fabric sheen from Clothing Pro, because a room needs all three.

Added

  • A shader built for worlds. Put it on any surface in your scene. Everything the avatar shaders do is here: the shading styles, five matcap layers, Car Paint, three glitter layers, five emission layers, decals, two outlines, and the whole set of special effects.
  • Wet Effects and Goo Effects. Water beads and runs down tile, soaks into stone and leaves a film on glass. Goo drips, clings, pools on the floor and crawls. They were built for latex on an avatar and they turn out to be exactly what a bathroom, a slime cave or a rain-soaked street wants.
  • Cloth and fibre, without geometry. The soft edge glow of silk, satin and velvet, and a painted-on fibre highlight for upholstery, carpet edges and moss on stone. Neither grows geometry, so neither costs you framerate.
  • LTCGI, and it belongs here. LTCGI's author discourages it on avatars and points them at Light Volumes instead. In a world it is the right tool: your emissive surfaces become real area lights, so a screen or a neon sign actually lights what is near it. Light Volumes, VRSL stage lighting and AudioLink are all here too, and they run together.
  • Every AudioLink effect comes across. The response engine, Chromatic Bloom, Note Swarm, Sonar, Spectrum Ribbon and the Cybernetic overlays. A club wall can read the music the same way an outfit can.
  • Lighting Check. Under RENDERING. Paints the surface with the light actually reaching it, so you can see which system your world is lighting it with. Set it back to Off before you upload.

Notes

  • For carpets and rugs, use World Fur instead. Real Fur grows actual standing strands, and it lives in that shader. World Surface has the painted-on Surface Fur only.
VixForge / World Fur 1.0.0 - Unreleased

Cosy, in a world. Carpets you want to sit on, shaggy rugs, moss over stone, grass across a field. It grows real strands off the surface, so the pile has depth you can see from the side instead of being a picture of fur painted on a plane.

Added

  • Real Fur, for a room. Standing strands stacked in thin layers. Length and Density set the coat, Tufting clumps it into locks, and Droop and Wind Sway make it hang and move. Use the mask to grow it only where you need it. It builds real geometry, so keep Strands Per Face and Curve Segments as low as still looks good.
  • Surface Fur underneath it. A painted-on fibre highlight that costs nothing and fills in the backing between the strands, so the pile does not thin out into bare floor when you look straight down at it.
  • It keeps the cloth sheen that Fur Pro drops, so a rug can be velvet. Everything else the avatar shaders do is here too: the shading styles, matcaps, Car Paint, glitter, emissions, decals, outlines and the special effects.
  • LTCGI, Light Volumes, VRSL and AudioLink. All four, running together. LTCGI is the one that changes most in a world: your emissive surfaces become real area lights, which is what its author built it for.
  • Lighting Check. Under RENDERING. Paints the surface with the light actually reaching it, so you can see which system your world is lighting it with. Set it back to Off before you upload.

Notes

  • No Wet or Goo here, on purpose. A carpet has no use for them and the textures are not free, so they are left out to keep the shader lighter. World Surface has both if you want a wet floor next to the rug.
