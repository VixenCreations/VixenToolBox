Core Documentation

Under the hood of the VixenTools ecosystem. A technical breakdown of the heuristics, math libraries, procedural pipelines, and real-world implementation driving the editor utilities.

Vixen Hub & DOM Bridging

VixenHub.cs

The flagship entry point. Engineered to entirely bypass legacy OnGUI redraw lag, the Hub utilizes a custom Markdown-to-UIToolkit Parser. It autonomously reads repository manifests and dynamically spawns native VisualElements, maintaining layout stability without locking the Editor thread.

  • Autonomous Scene HUD: Injects a sleek, non-blocking >> VIXENTOOLS UPDATE notifier directly into the Unity Scene View via Handles.BeginGUI(). This passively monitors state via an [InitializeOnLoad] hook, completely preventing workflow-breaking popups.
  • Action Delegate Routing: Overhauls markdown rendering by parsing [text](url) syntax mid-paragraph. It dynamically spawns transparent Button elements inline, mapping standard URLs to Application.OpenURL and custom internal commands directly to C# System.Action delegates.

In Practice: The Workflow

  • Interface Execution: Accessible via VixenTools > Hub Dashboard, the interface successfully translates the web's neon-pink/cyan aesthetic into Unity's native Editor styling.
  • Live Parsing: The tool autonomously extracts the exact ecosystem version natively from package.json and parses CHANGELOG.md into highly readable UI toolkit sections without horizontal scrolling constraints.

Quest Conversion Engine

QuestConversionEngine.cs

A highly optimized, non-destructive pipeline built to intercept and mathematically calculate VRChat Mobile Performance ranks natively. It isolates the prefab into a temporary conversion sandbox to ensure your base PC avatar is never irreversibly altered.

  • Magick.NET Linear Downsampling: Intercepts textures and processes them through a Lanczos filter natively. Textures are temporarily shifted into ColorSpace.RGB (Linear) to prevent highlight crushing during scaling, followed by a mathematically calculated UnsharpMask(0.0, 0.5, 1.0, 0.05) to recover high-frequency material details lost in standard Android ASTC compression.
  • Heuristic Culling Matrix: Executes a recursive deep-scan to isolate and forcefully purge globally banned mobile components (Cameras, AudioSources, Cloth, Unity Constraints, etc.). Integrates skeletal depth calculation to cull deep leaf bones based on performance targets.
  • Root Animator Protection: Employs a recursive depth scanner that detects the avatar's core root Animator, hard-locking it to a protected state so heuristic culling never accidentally shatters base functionality.

In Practice: The Workflow

  • Selective Culling: Upon initiating a scan, the interactive topology matrix populates. Creators can manually intervene before generation, such as intentionally keeping the tail, ears, and mane, while discarding expensive chest fluff to save geometry.
  • Post-Conversion Material Tweaks: The engine defaults materials to target specific mobile shaders like VRChat/Mobile/ToonLit. After the clone is generated, minor adjustments bring it to parity (e.g., setting particle lenses to Multiply, resetting emission maps, and utilizing Additive rendering on visors to recover transparency).
  • Bypassing Artificial Blocks: The engine accurately flags when a "Very Poor" ranking is caused strictly by the immutable 20,000 triangle limit rather than actual unoptimized components. It provides a bypass to compile the avatar anyway, allowing publication for showcase purposes.
  • VRC Fury Integration: Designed to stack with other optimization tools. Post-conversion, users can inject a VRC Fury Blend Shape Optimizer to aggressively purge unused blendshapes and drag Android performance overhead even lower.

PhysBone Topology Mapper

PhysBoneTopologyMapper.cs | PhysBoneBlueprint.cs

Designed to eliminate the human error of manually dragging, dropping, and configuring colliders across avatar iterations. This engine entirely decouples the physics matrix from the mesh hierarchy.

  • Master Blueprints: Utilizes AnimationUtility.CalculateTransformPath to generate relative skeletal paths. Saves targeted physics components as serialized Unity Preset objects mapped securely to a custom ScriptableObject schema.
  • Flawless Injection: Safely searches the target avatar's hierarchy by relative path and re-injects the Presets perfectly. Features "Graceful Degradation," safely falling back to visual error states if the VRChat SDK goes missing from the environment.

In Practice: The Workflow

  • Creating the Blueprint: A creator selects their master PC avatar root and runs "Extract Master Copy". This recursively catalogs every physics script and saves it to a structured blueprint (e.g., Assets/VixenTools/Blueprints/NovaBeast_1.2_MasterTopology).
  • Restoring Stripped Physics: If an avatar has had its components stripped (such as during manual Quest conversion or destructive optimization), the user selects the stripped avatar and hits "Inject". The mapper autonomously traverses the skeletal structure and reapplies the data. For instance, injecting the blueprint perfectly restores 14 distinct physics presets accurately across the entire rig in a single click.

Animation Workbench Pro

AnimationWorkbenchWindow.cs | PreviewEngine.cs | CurveOperations.cs

An advanced visual workspace for staging, easing, and sampling complex animation curves, built to bypass Unity's clunky default Animation window interface completely.

  • Runtime Math Library & Easing: Mathematical keyframe generation driven by EasingFunctions.cs. Supports programmatic interpolation (EaseInOutCubic, SmoothStep) seamlessly via CurveOperations.BuildStretchedCurve. Keys before the edit region are preserved, while intermediate keys are calculated and injected dynamically.
  • Live Preview Engine: Hooks into AnimationMode.StartAnimationMode() to dynamically sample targeted GameObjects, allowing real-time timeline scrubbing directly via the custom TimelineRibbon UI Component without altering actual scene states.
  • Multidimensional Material Extraction: Safely deconstructs Vector and Color properties on compiled shaders (like locked Poiyomi materials) into individually animatable float tracks to prevent native API crashes during curve bindings.

In Practice: The Workflow

  • Hidden Property Discovery: The MaterialPropertySearchPopup is utilized to read directly from a shader's active parameters. For example, it allows a creator to easily locate an obscure third-party property like _LumaFlowSpeed and extract its exact resting value (e.g., 0.00121).
  • Mathematical Smoothing: Rather than manually dragging bezier curves, a creator inputs the exact start and end values, selects a mathematical easing profile (e.g., SmoothStep), and defines key density. Generating 40 keys over 3 seconds creates a perfectly smooth stepped curve instantly.
  • Iterative Prototyping: The timeline can be scrubbed live via the PreviewEngine. If the animation feels too fast, the user can instantly re-generate the curve with 80 keys spread over 6 seconds, visually verifying the ultra-smooth transition directly in the editor without launching Play mode.

Vixen Badge Studio

VixenBadgeMaker.cs

A high-fidelity, CSS-driven procedural generation matrix utilizing a native JSON layout engine (layout.json) to architect multi-channel convention badges dynamically, specifically heavily targeting Furality templates.

  • Emissive Compositing Math: Fixes native Unity Standard Shader bloom blowouts. ImageMagick renders the generated text onto a pure MagickColors.Black background and mathematically flattens the output, permanently stripping the alpha channel before exporting the _EMI map to guarantee zero-bleed emission.
  • Universal Shader Injection: Automatically detects target shaders (Poiyomi, lilToon, VRC Mobile) and physically reaches into the compiled material to force-write user-selected Base and Emissive colors directly into the _Color and _EmissionColor slots.
  • Interactive Raycasting (UV Mapper): Temporarily suspends Unity gizmos and hijacks the Scene View. Raycasts against the MeshCollider, mathematically inverting 3D hits into 2D ImageMagick pixel space for perfect custom coordinate mapping.

In Practice: The Workflow

  • Automated Ingestion: After downloading the Furality SDK, the "Generate Furality JSON Layouts" button runs a Regex search algorithm to detect all convention badge components and builds strict spatial boundary rules (JSONs) for text injection autonomously.
  • Dynamic Shader Swap: Allows real-time transition of underlying shader properties. Switching a badge from a Standard shader to "Furality Aqua" recompiles the material on the fly, accurately placing the generated Diffuse and Emission textures into the new proprietary shader slots.
  • Live UV Repositioning: If a creator needs to adjust text placement, they don't need Photoshop. Activating the "Scene Mapping" raycaster attaches a temporary Mesh Collider. The user simply clicks on the badge in 3D space, which copies the X/Y intersection. Modifying the Width/Height bounds and recompiling uses ImageMagick to instantly expand and move the generated text.

Core Scene Utilities

BulkPresetGenerator.cs | SnapToSurface.cs | FixSceneData.cs

Background operations that maintain structural integrity and optimization standards across the Unity workspace.

  • Phantom Asset Architecture: BulkPresetGenerator.cs generates temporary "Phantom" textures, forces specific metadata onto them (like ASTC compression caps or NormalMap flags), extracts the configuration as a Preset, and injects it directly into Unity's Preset Manager to enforce global project consistency.
  • Geometric Surface Snapping: SnapToSurface.cs tracks Transform.hasChanged and mathematically calculates the absolute lowest boundary box across all child MeshRenderers and Colliders, dropping objects perfectly to the floor based on their physical geometric limits rather than an arbitrary center pivot.
  • Lightmap Serialization: FixSceneData.cs actively forces Unity to re-serialize the lightingDataAsset reference within the EditorSceneManager, fixing the notorious issue of missing or black lightmaps when transferring scenes between systems via VPM.

In Practice: The Workflow

  • Enforcing Rules: The Pipeline Preset Manager is used to dictate exactly how Unity handles newly ingested files. By establishing a phantom preset mapped to default resolution limits (e.g., max size 1024, Read/Write Enabled), the tool forcefully injects these rules directly into Edit > Project Settings > Preset Manager. Every subsequent file imported into the project automatically conforms to these boundaries, preventing accidental memory bloat from 4K/8K uncompressed textures.
