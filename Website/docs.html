Vixen Hub & DOM Bridging

VixenHub.cs

The flagship entry point. Engineered to entirely bypass legacy OnGUI redraw lag, the Hub utilizes a custom Markdown-to-UIToolkit Parser. It autonomously reads repository manifests and dynamically spawns native VisualElements, maintaining layout stability without locking the Editor thread.

  • Autonomous Scene HUD: Injects a sleek, non-blocking >> VIXENTOOLS UPDATE notifier directly into the Unity Scene View via Handles.BeginGUI(). This passively monitors state via an [InitializeOnLoad] hook, completely preventing workflow-breaking popups.
  • Action Delegate Routing: Overhauls markdown rendering by parsing [text](url) syntax mid-paragraph. It dynamically spawns transparent Button elements inline, mapping standard URLs to Application.OpenURL and custom internal commands directly to C# System.Action delegates.

In Practice: The Workflow

  • Interface Execution: Accessible via VixenTools > Hub Dashboard, the interface successfully translates the web's neon-pink/cyan aesthetic into Unity's native Editor styling.
  • Live Parsing: The tool autonomously extracts the exact ecosystem version natively from package.json and parses CHANGELOG.md into highly readable UI Toolkit sections without horizontal scrolling constraints.

Avatar Optimization Suite

VixenAvatarValidator.cs | VixenMeshPatcher.cs

A multi-threaded, highly destructive execution matrix designed to violently crush PC avatar polycounts and physics limits. It dynamically analyzes your hardware footprint and deploys a custom spatial hashing algorithm to decimate geometry while mathematically protecting high-fidelity facial topology.

  • 5D Spatial Hash Welder: Fuses co-located vertices on excessively heavy meshes (>15,000 polygons) by generating a proprietary 5-dimensional coordinate key. By mapping XYZ position natively alongside U and V coordinates, it drastically crushes raw polycounts while mathematically guaranteeing the survival of critical texture seams.
  • Dual-Shielding Exclusion Matrix: Automatically scans submesh material slots for high-detail keywords (e.g., eyes, visor, face) AND actively queries the active Humanoid Armature for HumanBodyBones.Neck. Any vertex influenced by these kinematics is locked entirely out of the decimation grid.
  • BlendShape Memory Recovery: Executing a destructive mesh wipe inherently annihilates Unity's blendshape delta arrays. The Welder caches all 175+ frames (visemes, facial expressions) prior to execution and mathematically averages the delta offsets across the newly fused vertices, allowing animations to perfectly survive aggressive topology meltdowns.
  • Kinematic Bounding Box Stabilization: Solves the bounding-box disappearance bug by encapsulating all 8 corners of the sharedMesh.bounds into absolute World Space, then projecting them backward into root-bone Local Space for a mathematically perfect, tight-fit bounds calculation.

In Practice: The Workflow

  • Dynamic PC Target Rank Matrix: Eradicates static culling limits. Creators explicitly target specific VRChat Performance Ranks (Excellent, Good, Medium, Poor) via a native dropdown. The deep-scanning heuristics instantly recalibrate execution thresholds for Animators, Contacts, and PhysBones based on the selected hardware constraints.
  • Interactive Physics Executioner: Replaces invisible auto-cull algorithms with a surgical UI Toolkit panel. Spawns an interactive matrix mapping every physics component sorted by hierarchy depth. Creators manually select and eradicate expendable leaf-node physics (tail fluff, hair tips) while visually protecting structural roots.
  • Deep Material Inspector Spider: Pierces through the Unity Inspector using EditorUtility.CollectDependencies. It spiders through Animator controllers and VRCFury outfit toggles, aggressively hunting down and caching nested textures to ensure the VRAM calculator and ImageMagick downsampler capture 100% of the avatar's actual memory footprint.

Quest Conversion Engine

QuestConversionEngine.cs

A highly optimized, non-destructive pipeline engineered to mathematically evaluate and map VRChat Mobile Performance ranks natively. The system isolates your avatar into a temporary conversion sandbox, ensuring your original PC prefab is never mutated or irreversibly altered.

  • Magick.NET Linear Downsampling: Intercepts all detected textures and processes them through a high‑fidelity Lanczos filter. Textures are temporarily shifted into ColorSpace.RGB (Linear) to prevent highlight crushing during scaling, followed by a precision-tuned UnsharpMask(0.0, 0.5, 1.0, 0.05) pass to restore micro‑detail typically lost in Android ASTC compression.
  • Base‑Class Heuristic Culling: Deep‑scans all <VRCPhysBoneBase> derivatives to capture 100% of physics variants, including VRCFury auto‑conversions and legacy migrations. The engine recursively purges globally banned mobile components such as Cameras, AudioSources, and Constraints.
  • IgnoreTransform Shield Piercing: Reads and interprets every ignoreTransforms array inside PhysBone components. If a bone is explicitly listed, the shield is dropped, allowing the culling matrix to correctly identify and remove dead leaf‑node bones that would otherwise survive heuristic filtering.
  • Deep Material VRCFury Cloning: Uses SerializedObject stream traversal to locate hidden materials inside VRCFury toggles, blend‑trees, and state behaviors. All discovered references are remapped to newly generated Android‑safe material variants, preventing pink‑shader failures at runtime.

In Practice: The Workflow

  • Selective Macro Culling: After scanning, the interactive topology matrix populates with all detected components. Global Keep All and Cull All macros allow creators to rapidly triage large arrays, preserving structural bones while discarding expensive fluff such as tail tips and hair strands.
  • Post‑Conversion Material Tweaks: The engine defaults all materials to mobile‑safe shaders such as VRChat/Mobile/ToonLit. After cloning, minor adjustments restore visual parity—resetting emission maps, applying Multiply blending to particle lenses, and enabling Additive rendering on visors to recover transparency.
  • Bypassing Artificial Blocks: When a “Very Poor” rating is caused solely by the immutable 20,000‑triangle cap rather than actual optimization issues, the engine exposes a bypass allowing creators to compile the avatar anyway for showcase or testing purposes.
  • Root Animator Protection: A recursive depth scanner identifies the avatar’s core root Animator and hard‑locks it, ensuring heuristic culling never destroys locomotion controllers, FX layers, or toggle logic.

PhysBone Topology Mapper

PhysBoneTopologyMapper.cs | PhysBoneBlueprint.cs

Designed to eliminate the human error of manually dragging, dropping, and configuring colliders across avatar iterations. This engine entirely decouples the physics matrix from the mesh hierarchy by snapshotting your PhysBone architecture into reusable blueprints.

  • Master Blueprints: Utilizes AnimationUtility.CalculateTransformPath to generate relative skeletal paths from a chosen avatar root. Each VRCPhysBone is serialized into a Unity Preset and stored in a custom PhysBoneBlueprint ScriptableObject, mapping bonePath → Preset with surgical precision.
  • Two-Phase Architecture: Phase 1 ("Extract Master Copy") walks the source avatar, generates presets under Assets/VixenTools/Blueprints/<Name>/Presets, and writes a master .asset blueprint. Phase 2 ("Inject Blueprint") traverses a target avatar by relative path, auto-adding VRCPhysBone components where missing and applying the stored presets.
  • Graceful Degradation: When the VRChat SDK is not present, the window falls back to a safe visual state. All destructive buttons are disabled and clearly labeled as SDK-dependent, preventing accidental misuse in non-VRChat projects.

In Practice: The Workflow

  • Creating the Blueprint: A creator selects their master PC avatar root and runs "Extract Master Copy". This recursively catalogs every physics script and saves it to a structured blueprint (e.g., Assets/VixenTools/Blueprints/NovaBeast_1.2_MasterTopology).
  • Restoring Stripped Physics: If an avatar has had its components stripped (such as during manual Quest conversion or destructive optimization), the user selects the stripped avatar and hits "Inject". The mapper autonomously traverses the skeletal structure and reapplies the data. For instance, injecting the blueprint can perfectly restore dozens of distinct physics presets accurately across the entire rig in a single click.

Animation Workbench Pro

AnimationWorkbenchWindow.cs | PreviewEngine.cs | CurveGraphView.cs | CurveOperations.cs | EasingFunctions.cs | MaterialPropertySearchPopup.cs | EasingDropdown.cs | TimelineRibbon.cs

An advanced visual workspace for staging, easing, and sampling complex animation curves, built to bypass Unity's clunky default Animation window completely. The Workbench treats curves, bindings, and material properties as a programmable matrix instead of a fragile hand-drawn timeline.

  • Runtime Math Library & Easing: Mathematical keyframe generation driven by EasingFunctions.cs. CurveOperations.BuildStretchedCurve rebuilds a curve between [sTime, eTime], preserving keys before the region while injecting intermediate keys using selectable easing (Linear, SmoothStep, EaseInOutCubic, etc.). Keys after the region are intentionally dropped, letting the generated segment define the tail.
  • CurveGraphView Engine: A custom VisualElement graph powered by IMGUIContainer. Supports zooming, panning, double-click key insertion, and right-click key deletion with per-binding color hashing. It computes dynamic value ranges and renders both continuous curves and discrete key markers.
  • Live Preview Engine: PreviewEngine hooks into AnimationMode.StartAnimationMode() and EditorApplication.update to sample clips directly on a target GameObject. It plays back at adjustable speed, stops automatically at clip end, and never dirties the scene hierarchy.
  • TimelineRibbon Range Control: A dedicated IMGUI ribbon that exposes start/end sliders for the active clip. It prevents zero-length collapse, supports expanding beyond clip length, and broadcasts range changes back into the graph and generation logic.
  • Multidimensional Material Extraction: The Workbench walks all renderers on a preview target, inspects shader properties, and explodes Color/Vector fields into per-channel float tracks (R/G/B/A, X/Y/Z/W). This prevents native API crashes and makes even locked Poiyomi properties fully animatable.
  • MaterialPropertySearchPopup: A dedicated search window that groups properties by Material → Category → Property. It supports fuzzy search, nested foldouts, and click-to-bind behavior, returning a structured entry back to the Workbench.
  • EasingDropdown Selector: A lightweight UI Toolkit control backed by GenericMenu. It renders textual previews of easing shapes and broadcasts changes via OnValueChanged, allowing global default easing to be applied across all selected bindings.

In Practice: The Workflow

  • Hidden Property Discovery: The MaterialPropertySearchPopup is utilized to read directly from a shader's active parameters. For example, it allows a creator to easily locate an obscure third-party property like _LumaFlowSpeed and extract its exact resting value (e.g., 0.00121).
  • Mathematical Smoothing: Rather than manually dragging bezier curves, a creator inputs the exact start and end values, selects a mathematical easing profile (e.g., SmoothStep), and defines key density. Generating 40 keys over 3 seconds creates a perfectly smooth stepped curve instantly.
  • Iterative Prototyping: The timeline can be scrubbed live via the PreviewEngine. If the animation feels too fast, the user can instantly re-generate the curve with 80 keys spread over 6 seconds, visually verifying the ultra-smooth transition directly in the editor without launching Play mode.
  • Explicit Intent Safeguards: Staged curves are held in an internal dictionary until the user explicitly applies or commits them. This prevents accidental destructive writes to live clips and keeps experimentation reversible.

Vixen Badge Studio

VixenBadgeMaker.cs

A high-fidelity, CSS-driven procedural generation matrix utilizing a native JSON layout engine (layout.json) to architect multi-channel convention badges dynamically, specifically heavily targeting Furality templates.

  • Emissive Compositing Math: Fixes native Unity Standard Shader bloom blowouts. ImageMagick renders the generated text onto a pure MagickColors.Black background and mathematically flattens the output, permanently stripping the alpha channel before exporting the _EMI map to guarantee zero-bleed emission.
  • Universal Shader Injection: Automatically detects target shaders (Poiyomi, lilToon, VRC Mobile) and physically reaches into the compiled material to force-write user-selected Base and Emissive colors directly into the _Color and _EmissionColor slots.
  • Interactive Raycasting (UV Mapper): Temporarily suspends Unity gizmos and hijacks the Scene View. Raycasts against the MeshCollider, mathematically inverting 3D hits into 2D ImageMagick pixel space for perfect custom coordinate mapping.

In Practice: The Workflow

  • Automated Ingestion: After downloading the Furality SDK, the "Generate Furality JSON Layouts" button runs a Regex search algorithm to detect all convention badge components and builds strict spatial boundary rules (JSONs) for text injection autonomously.
  • Dynamic Shader Swap: Allows real-time transition of underlying shader properties. Switching a badge from a Standard shader to "Furality Aqua" recompiles the material on the fly, accurately placing the generated Diffuse and Emission textures into the new proprietary shader slots.
  • Live UV Repositioning: If a creator needs to adjust text placement, they don't need Photoshop. Activating the "Scene Mapping" raycaster attaches a temporary Mesh Collider. The user simply clicks on the badge in 3D space, which copies the X/Y intersection. Modifying the Width/Height bounds and recompiling uses ImageMagick to instantly expand and move the generated text.

Core Scene Utilities

BulkPresetGenerator.cs | SnapToSurface.cs | FixSceneData.cs

A high-performance suite of background operations and spatial automation scripts engineered to enforce structural integrity, optimization standards, and geometric precision across the Unity workspace.

SPATIAL TOPOLOGY TOOLS

  • Live Surface Snapping (Dual-Matrix Gravity): Utilizes low-overhead Transform.hasChanged tracking to simulate autonomous gravity for objects moved via the transform gizmo. It calculates bounding-box nadirs on the fly to drop assets perfectly flush with underlying geometry the moment the mouse is released.
  • Precision Click-to-Place Raycaster: A sniper-rifle camera raycaster enabling creators to paint/teleport objects onto complex shelf polygons or terrain. Guided by a cyan/magenta UV projection disc, it calculates surface normals to instantly align selected assets with 100% geometric accuracy.
  • Surgical Shielding & VRC-Layer Masking: Features a bitwise layer mask (~((1 << 2) | (1 << 4)...)) to explicitly ignore VRChat-specific utility layers (Water, UI, Pickup, etc.). It autonomously caches and disables child colliders during execution to prevent self-occlusion deadlocks.

INFRASTRUCTURE & RECOVERY

  • Pipeline Preset Manager (BulkPresetGenerator.cs): A unified pipeline tool that handles both bulk extraction of presets from existing assets and programmatic authoring of standardized importer presets using a Phantom Asset architecture. It exposes two modes: Extraction Pipeline and Authoring Engine, switchable via neon-styled tabs.
  • Bulk Preset Extraction: Rips component configurations from selected GameObjects (optionally including children) into reusable Preset assets. It can ignore Transform components, auto-register new presets into Unity's Preset Manager, and names files by object and component type for instant traceability.
  • Phantom Asset Authoring: Programmatically authors standardized texture importer presets without needing a source asset. It generates a temporary PNG "Phantom" texture, configures TextureImporter (type, max size, mipmaps, readability), then rips that configuration into a permanent Preset and injects it into the Preset Manager with an optional glob filter (e.g., glob:"**/*_BaseColor.png").
  • Preset Manager Injection: Uses Preset.GetDefaultPresetsForType and Preset.SetDefaultPresetsForType to prepend new defaults, ensuring newly imported assets automatically conform to your global standards (NormalMap flags, ASTC caps, mip rules) without manual configuration.
  • Udon State Serialization: Snapping logic is tied directly into the Udon Virtual Machine via EditorUtility.SetDirty. This ensures that snapped objects hosting UdonBehaviour components correctly register hierarchical changes, preventing catastrophic position rollbacks during world builds or network syncs.
  • Lightmap Serialization Engine: FixSceneData.cs actively forces the re-serialization of lightingDataAsset references within the EditorSceneManager, fixing the notorious issue of black or missing lightmaps when transferring scenes between systems via VPM.

In Practice: The Automated Workflow

  • Spatial Triage: By establishing a 1024px ASTC phantom preset, the tool forcefully injects memory boundaries into Edit > Project Settings > Preset Manager. Every subsequent file conforms to these rules. Simultaneously, SnapToSurface.cs ensures that every asset spawned into the scene conforms to the environment's physical limits, using dynamic iteration to locate the absolute minimum global Y-bound across all mesh renderers and child colliders.

Vixen World Engine

VixenWorldSpider.cs • UdonSharpEditorCache.cs • VixenEngineStressTest.cs

The Vixen World Engine is a full-spectrum scene auditor built for VRChat creators who need real‑time diagnostics, topology forensics, and automated repair protocols. Operating on a deep-reflection layer, the engine pierces Unity, Udon, and third‑party assemblies to expose hidden performance traps long before they detonate in a live instance.

ECOSYSTEM & TOPOLOGY AUDITORS

  • ProTV Guard: Detects HDR VRAM bloat, conflicting Global Shader Variable (GSV) baking, realtime emissive GI blowouts, playlist search aggression, and RTGI mobile sinks. Automatically throttles unsafe fields via reflection.
  • IwaSync3 Matrix: Flags 1080p+ video blowouts, unbounded playlist growth, global non‑spatialized audio, aggressive sync frequencies, emissive screen overdrive, and GC‑heavy event invokers.
  • TXL Logic Scraper: Detects starvation‑level polling (monitorTriggerInterval = 0.01f), collapsed translation tables, forced collider checks, orphaned Udon behaviours, and cryptographic sinks from DigestValidator.
  • Mesh & Geometry Hunter: Identifies 66k+ vertex meshes, missing LOD chains, non‑convex MeshCollider drag, realtime reflection probes, and physics sinks that destabilize frame pacing.
  • Stress Test Fabricator: Generates a full Omni‑Chaos environment with realtime lights, reflection probes, VRAM nukes, 4K textures, heavy meshes, network sync storms, and video pipeline overloads.
  • Lighting & Camera Auditor: Ensures world descriptors, spawn points, and baseline lighting exist, preventing SDK validation failures and broken world boot sequences.

UI, SECURITY & MEMORY SENSORS

  • Raw UASM Scraper: Intercepts UdonSharpEditorCache to analyze raw Udon assembly. Detects lethal PlayerData.Set calls inside Update(), infinite sync loops, and network‑rate‑limit bombs before they reach a build.
  • UI & Font Integrity: Flags deprecated Arial.ttf, mismatched TMP assets, missing shader channels, and world‑space canvases that trigger rebuild cascades.
  • Shader & Asset Whitelist: Protects core SDK shaders, IwaSync internals, ProTV internals, and VRC Billiards materials from the autonomous shader replacer.
  • Hardware‑Level VRAM Security: Uses Profiler.GetRuntimeMemorySizeLong() to capture true GPU footprint, exposing procedural 4K RenderTextures, TMP atlases, UI masks, and hidden memory hogs.
  • Canvas Rebuild Tracker: Detects layout‑modifying elements on root canvases, preventing catastrophic rebuild storms in playlist UIs and queue systems.
  • Video Pipeline Throttling: Monitors video players, sync frequencies, and networked playback logic to prevent runaway bandwidth usage and frame pacing collapse in high-traffic instances.
