Ecosystem Breakdown

  • Vixen Hub: A centralized developer dashboard unifying ecosystem documentation and the native CHANGELOG.md parser into a single interface. Features a custom UV-framing engine for dynamic header scaling.
  • Vixen Badge Studio: A high-fidelity, procedural generation engine for VRChat convention badges (natively supporting Luma, Somna, Sylva, and Umbra). Features an Ecosystem Discovery Engine, Universal Shader Targeting, and Dynamic UV Auto-Layouts.
  • Animation Workbench Pro: An advanced visual workspace for staging, easing, and sampling complex animation curves. Features interactive timeline ribbons and a runtime-safe math library (`EasingFunctions.cs`).
  • PhysBone Topology Mapper: Automates complex physics architecture through a two-phase Extraction and Injection process, completely bypassing native Unity prefab constraints.
  • Pipeline Preset Manager: Handles bulk extraction of configuration presets and the programmatic authoring of standardized importer settings using a "Phantom Asset" architecture.

Ecosystem Changelog

v1.2.0 - 2026-04-20

Added

  • Vixen Hub Integration: Merged standalone parsers into a unified, tabbed Editor dashboard.
  • Ecosystem Discovery Engine: Badge Studio passively scans the project hierarchy to detect Furality SDKs, bypassing year-to-year folder restructuring.
  • Universal Shader Targeting: Heuristic engine automatically detects and configures targets across Poiyomi, lilToon, VRChat Mobile, and legacy convention shaders.
  • Dynamic UV Auto-Layout: Badge Studio automatically adjusts localized text bounds, rotations, and signature neon hex colors to match specific convention years.

Fixed

  • Emission Blackout Safeguard: Added failsafe to detect and override black or transparent `_EmissionColor` multipliers on legacy materials.

v1.1.1 - 2026-04-18

Added

  • Destructive Pipeline Operations: Integrated "Delete Selected" function within Animation Workbench to prune dead property tracks safely.

Changed

  • Explicit Intent Paradigm: Flipped default states for "Sample Start/End Value" to false, preventing destructive scene data overrides.
