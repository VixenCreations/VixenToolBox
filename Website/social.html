Getting Started & Getting Help

New to the Vixens Toolbox, or stuck on something? This is your map. Follow the steps below, from your first install all the way to reporting a bug.

1. Start Here: Watch the Walkthrough

Brand new? Start with this. It is a complete, in-depth breakdown of what the suite does, how the pipeline fits together, and how to radically optimize your Unity environment, so the rest of the docs make sense before you dive in.

2. Install It & Read the Docs

Add the registry to the VRChat Creator Companion, then keep the docs open while you work. Every tool has a step-by-step guide.

3. Get Help When You're Stuck

The fastest answers come from the community. Hop into Discord, describe what you are trying to do, and someone (often me) will help you sort it out.

Open a GitHub issue. Tell me what you expected, what actually happened, and your Unity / VRChat SDK versions, that's all I need to start fixing it.
