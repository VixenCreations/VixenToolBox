VixenLens

Repository

A standalone, high-performance metadata indexing and retrieval engine. Built utilizing a Rust backend and a Tauri frontend, VixenLens is engineered to autonomously traverse and index thousands of VRChat snapshots, providing 4D-chess-level organization for massive historical archives.

Rust Tauri Metadata Parsing

Fish Validator

Repository

A robust, community-focused validation engine designed to seamlessly appraise and validate structured data within specialized environments. Backed by a fully flushed-out ecosystem wiki for transparent documentation.

Data Validation Community Tool Wiki Documented

Stream Connector

Repository

An ultra-low-latency, multi-threaded orchestration engine that bridges live broadcast events straight into physical hardware states. Local-first and fail-closed, with a tri-state concurrency core and a haptic abstraction layer spanning PiShock, Intiface, OWO and OSC.

Python / asyncio Local-First Haptics & OSC
