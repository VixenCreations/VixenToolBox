3. Bounce. Unity: indirect colour = direct colour * Light.bounceIntensity (Indirect Multiplier).
   Baker today: every light bounces at 1. A light at Indirect Multiplier 0 still bounces fully; one at 2 bounces half as much as in Unity.

4. Soft shadows. Unity: sphereRadius = shadowRadius only when Shadow Type is Soft (angularDiameter the same for
   directional). Baker today: uses shadowRadius / shadowAngle for any shadowed light, so a Hard-shadow light bakes soft.
