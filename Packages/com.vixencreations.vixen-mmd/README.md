# VixenMMD

Gets your avatar dancing in MMD worlds. Those worlds animate a set of Japanese face shapes most VRChat avatars don't have, so your body dances and your face stays still. VixenMMD builds those shapes from your avatar's face tracking shapes and visemes when you upload or enter Play Mode, so your avatar files never change. It takes over from Make It MMD.

* **Package:** `com.vixencreations.vixen-mmd` (v1.0.0)
* **Needs:** Unity 2022.3.22f1, VRChat Avatars SDK 3.10.6 or newer, and NDMF 1.14.7 or newer, which comes with Modular Avatar
* **Docs:** [vixencreations.github.io/VixenToolBox/tools.html](https://vixencreations.github.io/VixenToolBox/tools.html#vixenmmd)

## Install

Add the Vixens Toolbox listing to the VRChat Creator Companion from [vixencreations.github.io/VixenToolBox](https://vixencreations.github.io/VixenToolBox/), then add **VixenMMD** to your avatar project. It doesn't need the rest of the toolbox. The Creator Companion installs NDMF with it, so add the Modular Avatar listing (`https://vpm.nadena.dev/vpm.json`) first if you don't have it yet.

## Use it

1. Select your avatar and open `VixenTools/Avatars/VixenMMD`, or use **Add Component > VixenTools > VixenMMD**.
2. Coming from Make It MMD? Press **Convert Make It MMD Setup** and you're done.
3. Otherwise, open **Auto-fill**, press **Guess Empty Ones**, then **Preview Changes** and apply.
4. Before a dance night, add the dances' `.vmd` files to **Dance Check** and fill in whatever is missing.
