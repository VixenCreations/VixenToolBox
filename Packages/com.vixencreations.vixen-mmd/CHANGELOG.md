# VixenMMD - Changelog

All notable changes to VixenMMD are documented in this file.

***
## [1.0.0] - 2026-11-13
*VixenMMD has its own package now, so it only loads in the avatar projects you add it to.*

### Heads up

* **VixenMMD needs VRChat SDK 3.10.6 and NDMF 1.14.7 or newer.** The Creator Companion updates both when you add VixenMMD. If it can't find NDMF, add the Modular Avatar listing (`https://vpm.nadena.dev/vpm.json`) first.

### Added

* **VixenMMD as its own package**, next to the Vixens Toolbox in the same listing. It's the VixenMMD from Vixens Toolbox 2.21.1, with the same features, and your avatars keep their VixenMMD settings. It doesn't need the rest of the toolbox.

### Notes

* VixenMMD's earlier changes are in the Vixens Toolbox changelog, under 2.21.0 and 2.21.1.
